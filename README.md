This is a little project to create a overlay of Dead By Daylight Clock Callouts. Written in C++

Edit dbdoverlay.desktop with you're favorite IDE

Exec=[Path to Executable]

Change the path to executable to the path where the dbdoverly executable is located in double quotes.
Example:

Exec="/home/user/Projects/dbdcco"

The run the install script by typing:

chmod +x install.sh

This line allows Linux to see 'install.sh' as an executable

Then Type:

./install.sh

This runs the executable and moves the dbdoverlay.desktop to /home/.local/share/applications/[dbdoverlay.desktop]
